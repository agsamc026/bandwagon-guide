## FAQ

**Q：搬瓦工新用户有没有注册优惠或首单折扣？**

目前搬瓦工没有专门的新用户注册折扣。常规优惠码在2025年11月底已集体失效，目前暂无可用全场码。最实际的省钱方式是：年付比月付便宜（相当于多两个月免费），或者等限量版套餐出现时抢购。

**Q：支付宝能付款吗，需要美元账户吗？**

支付宝直接付款，不需要美元账户。官网结账时选 Alipay，然后扫码或输入账号密码完成支付，人民币直接扣。

**Q：买完机房能换吗？换了会不会影响数据？**

KVM 套餐支持在一定范围内迁移机房，CN2 GIA-E 套餐支持的机房更多（超过12个）。迁移操作在 KiwiVM 后台一键完成，数据保留，不影响已有配置。

**Q：搬瓦工的 30 天退款是怎么算的？**

从购买成功日期算起30天内。后台进 Billing → 提交退款申请，系统自动审核，一般几个工作日内原路返回。需要满足退款条件（具体可在官网查看），一般不存在问题。

**Q：什么是 CN2 GIA，和 CN2 GT 区别大吗？**

CN2 GIA 是电信最高端的国际线路，全程走 AS4809 网络，国内外都走 CN2，延迟低、丢包少，三网（电信/联通/移动）用户都受益。CN2 GT 则是混合线路，出国段走 CN2，但国内段回程走普通 163 骨干网，高峰期容易有波动。体验上 CN2 GIA 明显更稳。搬瓦工 KVM 套餐接的是 CN2 GT，CN2 GIA-E 和香港、东京套餐接的是 CN2 GIA。
